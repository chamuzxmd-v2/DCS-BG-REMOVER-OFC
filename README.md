# 🟢 NeonCut BG Remover

**NeonCut BG Remover** is a modern, mobile-friendly web application that removes image backgrounds instantly using AI technology.

Built with a clean cyber-neon UI and optimized for mobile devices.

---

## 🚀 Live Demo
👉 https://chamuzxmd-v2.github.io/DCS_BG_REMOVER_OFC/

---

## ✨ Features
- 📱 Fully mobile responsive
- 🖼 Upload images directly from phone or PC
- ✂ One-click background removal
- ⬇ Download background-removed image
- 🎨 Neon green cyber-style UI
- ⚡ Fast & lightweight

---

## 🛠 Technologies Used
- HTML5  
- CSS3  
- JavaScript  
- remove.bg API
